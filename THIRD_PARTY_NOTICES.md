## Mousecape

Project: [alexzielenski/Mousecape](https://github.com/alexzielenski/Mousecape)

Cursor Studio consulted Mousecape as a technical research reference for the
existence, names, and expected purpose of unsupported CoreGraphics cursor
registration APIs and cursor identifiers. Cursor Studio's Swift implementation,
runtime symbol loader, persistence, models, UI, proof program, and generated
demo artwork are original; no Mousecape source file or bundled cursor artwork
is copied into this repository.
